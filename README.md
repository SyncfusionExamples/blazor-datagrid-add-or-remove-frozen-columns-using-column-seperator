# Blazor DataGrid - Add or Remove Frozen Columns Using Column Separator

A comprehensive example demonstrating how to use column separators to dynamically freeze and unfreeze columns in a [Blazor DataGrid](https://www.syncfusion.com/blazor-components/blazor-datagrid) with an interactive interface.

## Overview

This Blazor application showcases a practical implementation of the Blazor DataGrid's column freezing functionality. Users can interact with the grid by dragging the freeze line separator to dynamically freeze or unfreeze columns without writing additional code. The example displays a sample order dataset with columns frozen on both the left and right sides of the grid.

### Key Features

- **Interactive Column Freezing** - Drag the column separator to freeze/unfreeze columns in real-time
- **Multi-directional Freezing** - Freeze columns on both left and right sides
- **Rich Data Display** - Displays order data with multiple column types (text, date, currency)
- **Sorting Capability** - Sort columns to organize data
- **Responsive Grid** - Adaptive layout with fixed height and horizontal scrolling

* [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/SyncfusionExamples/blazor-datagrid-add-or-remove-frozen-columns-using-column-seperator.git
cd blazor-datagrid-add-or-remove-frozen-columns-using-column-seperator
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
